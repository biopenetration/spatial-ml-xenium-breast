# Data

Raw and processed data are **not** stored in this repository (they are large and governed by the 10x Genomics terms for the dataset).

* Download: `python scripts/download_data.py --out data/raw` (public Xenium FFPE Human Breast Cancer, Rep 1: `cell_feature_matrix.h5`, `cells.csv.gz`).
* Intermediate files written by the notebooks (annotated `.h5ad`, feature tables, checkpoints) go to your Google Drive project folder and are git-ignored.
